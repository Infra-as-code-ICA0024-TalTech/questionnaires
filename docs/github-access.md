# GitHub access

This work-in-progress repository is published as a private repository in `Infra-as-code-ICA0024-TalTech`, following the existing demo repositories.

The organization has **Read** base repository permission, checked on 21 September 2026 using the authenticated GitHub API. All organization members can therefore read the questions, answer key, and generated exports. The instructor explicitly approved publication with these existing permissions. Organization permissions have not been changed.

Private visibility limits access outside the organization to users granted access; it does not hide this repository from organization members. Organization owners retain access.
